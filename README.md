### 🟣 QUEST 02 — MY POKÉDEX

**Mobile Application**

Aplicativo mobile desenvolvido com React Native e Expo, inspirado em uma Pokédex.

### 🟠 QUEST 04 — RIVER MONITORING

**IoT & Environmental Monitoring**

Protótipo de monitoramento de rios em áreas rurais, utilizando sensores para acompanhar parâmetros da água e indicar possíveis situações de risco.

- Monitoramento de TDS, relacionado à concentração de sólidos dissolvidos.
- Medição do nível da água com sensor ultrassônico.
- Integração com ESP32.
- Visualização remota de informações pelo Blynk.
- Alertas para valores que ultrapassam limites configurados.

<sub>TECH: C++ • ESP32 • Arduino IDE • IoT • Blynk</sub>
